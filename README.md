# Titus in Midgar

**Development source — not a playable release.**

A solo mashup hosted by Final Fantasy VII Remake Intergrade. Play Titus with his
Space Marine 2 combat and animations, select his weapons through FFVII's menus,
keep materia and party commands, and perform the For the Emperor emote.

Players must own and install both games. Game content must be read from those
installed copies in memory; no game content is included in this project.

The first validation slice covers one Chapter 1 fight, chainsword and bolter,
equipment switching and the emote. The full design also retains armor, contested
health, parries, gun strikes, executions, grenades and Fury.

No new runtime combat, mesh, emote or one-click installation has been proven.
The earlier mesh prototype and converted game files are not a release artifact.
License and permission to remix original project code are awaiting the creator.

Design is recorded in `Sheets/`; `Tools/Content/` performs read-only discovery.
